# odin-recipes
Imagine a recipe book, but online. By completing this project from the HTML Foundations section of The Odin Project you'll be demonstrating basic HTML skills. These include working an HTML file structure, heading hierarchy, creating paragraphs, inserting images, and linking pages. You'll also demonstrate that you're comfortable working with Git.
